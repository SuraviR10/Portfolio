Project Overview

01. What It Does

MITM-Time Evolver is an automated timetable generation system designed for MIT Mysore. It intelligently schedules classes while respecting institutional constraints.

02. Problem It Solves

Manual timetable creation is time-consuming, error-prone, and often results in clashes. This system automates scheduling, ensuring optimal resource utilization and zero conflicts.

03. Why It Was Built

Built to address the real-world administrative challenge faced by academic institutions in creating efficient timetables that satisfy faculty availability, room capacities, and student schedules.

Key Features

Intelligent Scheduling

Uses advanced Genetic Algorithms to generate optimal timetables.

Constraint Handling

Respects faculty availability, room capacity, and time slots.

Conflict Resolution

Automatically detects and resolves scheduling conflicts in real-time.
