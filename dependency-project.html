Project Architecture & Briefing

01. Problem & Friction

Developers frequently encounter `ModuleNotFoundError` or package conflicts that break their workflow. Moving to an external terminal to debug environment aliases wastes time and degrades developer focus.

02. Intelligent VS Code Engine

DARTX silently listens to terminal execution streams, isolates missing package tracebacks, maps import aliases (e.g. `cv2` → `opencv-python`, `PIL` → `Pillow`), and presents secure 1-click install notifications.

03. Security & Marketplace Status

Enforces strict command and package validation against official registries to prevent typosquatting attacks. Published live on the VS Code Extension Marketplace for community installation.
