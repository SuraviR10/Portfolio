DARTX – Smart Dependency Manager & Scanner

A developer productivity tool for VS Code that performs AST-based import scanning, catches missing runtime packages, resolves tricky alias mappings, and executes secure 1-click package installations directly inside the editor.

Engineering Architecture & Solution

01. Problem: Dependency Friction & Tracebacks

Developers cloning unfamiliar repositories or collaborating on multi-package Python and JavaScript projects frequently hit cryptic ModuleNotFoundError or uninstalled package errors. Leaving the editor to search for package names disrupts developer flow.

02. Intelligent Alias Mapping & Detection

Many popular libraries have import names that differ from their package install names (e.g., importing cv2 requires pip install opencv-python; importing PIL requires pip install Pillow). DARTX includes a curated alias resolution database to prevent install failures.

03. Registry Validation & 1-Click Install

Integrates VS Code notifications with secure subprocess triggers to execute pip/npm installation in the active virtual environment, verifying package names against official registries to prevent typosquatting security vulnerabilities.

04. Published Extension & Real Impact

Packaged using vsce and published on the official Visual Studio Code Marketplace, delivering a friction-free developer experience for students, hobbyists, and professional software engineers.
