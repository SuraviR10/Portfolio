SMART LAB: AI-Powered C Programming Lab Assistant

An intelligent academic laboratory assessment platform that combines GCC/MinGW automated compilation, regex/AST error translation into plain English, dual-tier test case evaluation (public + hidden), and automated lab manual PDF extraction.

System Architecture & Core Capabilities

01. Problem: Lab Bottlenecks & Delayed Feedback

With 60+ students per programming lab section, faculty and teaching assistants face severe bandwidth limits answering repetitive syntax questions and grading student code manually. Cryptic compiler warnings frequently stall beginner students for 20+ minutes on trivial mistakes.

02. Automated Compilation & Error Translation

SMART LAB runs GCC/MinGW subprocess sandboxes to compile student C submissions. It parses stderr outputs and regex maps cryptic errors (e.g. missing semicolons, type mismatches, segmentation faults) into clear, step-by-step guidance without giving away answers directly.

03. Automated Test Execution & Assessment

Every submission is evaluated against both public sample test cases and hidden edge test cases with execution timeouts to prevent infinite loops. Detailed reports show passed test assertions, runtime efficiency, and logic accuracy.

04. Syllabus PDF Extraction & Problem Bank

Includes an automated syllabus parser that ingests university lab manual PDFs, extracts problem statements and constraint definitions, and automatically generates starter test cases into a structured SQLite problem repository for instructors.
