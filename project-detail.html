MITM-Time Evolver

Intelligent Timetable Generation System with Constraint Handling

Python Algorithms Optimization Flask

Project Overview

What it does: MITM-Time Evolver is an automated timetable generation system designed specifically for MIT Mysore. It intelligently schedules classes while respecting multiple institutional constraints.

Problem it solves: Manual timetable creation is time-consuming, error-prone, and often results in conflicts. This system automates the entire process, ensuring optimal resource utilization and conflict-free schedules.

Why it was built: To address the real-world challenge faced by academic institutions in creating efficient timetables that satisfy faculty availability, room capacity, and student requirements.

Important Constraints & Assumptions

Time Constraints

  • Maximum 6 hours per day per faculty
  • Minimum 1-hour break for lunch
  • No back-to-back theory classes for students

Room Constraints

  • Room capacity must match class size
  • Lab sessions require specific lab rooms
  • One room cannot host multiple classes simultaneously

Faculty Constraints

  • Faculty availability windows respected
  • No faculty can teach two classes at once
  • Subject-faculty mapping is predefined

System Limitations

  • Maximum 500 students per batch
  • Up to 50 faculty members supported
  • Generation time: 2-5 minutes for complex schedules

How It Works

Step 1

Data Collection

Admin inputs faculty details, subject list, room information, and time slot preferences through a web interface.

Step 2

Constraint Validation

System validates all inputs and checks for constraint violations before proceeding to generation phase.

Step 3

Algorithm Execution

Genetic algorithm creates multiple timetable candidates, evaluates fitness based on constraints, and evolves towards optimal solution.

Step 4

Conflict Detection

System performs final validation to ensure zero conflicts in faculty schedules, room allocations, and student timetables.

Step 5

Output Generation

Final timetable is displayed on dashboard and can be exported as PDF or Excel for distribution.
