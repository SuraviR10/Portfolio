## Step 2: Set Up Contact Form (5 minutes)

### Why?
The contact form needs Formspree to work. It's free and takes 5 minutes.

### How:
1. Go to: **https://formspree.io**
2. Click "Get Started" (free)
3. Sign up with your email
4. Click "+ New Form"
5. Name it: "Portfolio Contact"
6. You'll get a code like: `xyzabc123`

### Update Your Code:
1. Open `index.html` in editor
2. Find this line (around line 240):
   ```html
   <form ... action="https://formspree.io/f/xyzabc" ...>
   ```
3. Replace `xyzabc` with your code
4. Save file
5. Test the form - it works now! ✅
